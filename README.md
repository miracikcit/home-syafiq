# Home Syafiq

App keluarga (PWA) untuk iPhone: Home, Finance, Checklist, Goals.

- Kod sahaja. Tiada data dalam repo ni. Data dalam Google Sheet keluarga, dibaca melalui Apps Script yang perlukan kod rahsia keluarga.
- `apps-script/Code.gs`: backend, ditampal dalam Sheet SPENDING (Extensions › Apps Script).
- `./deploy.sh "apa diubah"`: hantar versi baru ke semua phone.
